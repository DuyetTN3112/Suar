# Project Delivery Activity Diagrams

| Tầng | Diagram |
|---|---|
| Overview | project preparation; delivery/review |
| High level | staffing, role/skill governance, sprint planning board |

`act_04a` là bản đồ staffing ngắn. `act_04a1` và `act_04a2` tách input của owner khỏi xử lý staffing của hệ thống.

Delivery/review overview hiện dùng bốn shared Project boards. Task vẫn ở lane Done của Task Board khi card tương ứng bắt đầu tại `awaiting_review` trên Task Review Board.
