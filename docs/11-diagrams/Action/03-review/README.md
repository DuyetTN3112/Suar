# Review Activity Diagrams

| Tầng | Diagram |
|---|---|
| Overview | observation collection; response/resolution |
| High level | submit, confirm, score, dispute, sprint review close |
| Low level | anomaly moderation, profile-score recalculation |

Overview nối tới workflow chính; low-level giải thích hậu xử lý và governance chuyên biệt.

`act_03d` giữ rõ handoff giữa User realm và System realm: User tiếp tục dùng Project board, còn System Admin xử lý case trên `/admin/disputes`. `act_03e` mở hai Project board assigner/environment, không tạo User/Org page riêng.
