The three overview frames form one formal Level~2 expansion of P5, not three separate levels. D4
is the explicit handoff: the lifecycle frame records submitted review/evidence state, the governance
frame owns the human decision and optional signed advisory boundary, and the profile frame projects
only valid governed observations. The split is justified by distinct authority and trust boundaries,
while preserving P5's named stores and outcomes on portrait A4.

Đọc overview → high-level map → low-level atomic flow. Mỗi low-level file chứa một câu chuyện dữ liệu; các bước nối tiếp không tách khi vẫn là một pipeline thống nhất.
