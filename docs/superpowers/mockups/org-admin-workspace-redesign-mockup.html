Org workspace redesign / scoped workspace

Tách rõ org, project, task để user không còn phải tự đoán scope.

Bộ mockup này mô tả đích UX cho org owner và org admin: sidebar theo job-to-be-done, dashboard làm decision hub, project detail trở về đúng vai trò container, và task board luôn nói rõ đang điều phối trong project hay toàn tổ chức.

Miền 1 Org Members, roles, permissions, invitations, settings.
Miền 2 Project Portfolio, staffing, role baseline, project configuration.
Miền 3 Task Board, list, triage, workflow, daily execution decisions.

Điểm cần nhìn khi review

  • Sidebar không còn nhóm mơ hồ `Công Việc`.
  • Dashboard `/org` dẫn user vào đúng miền cần xử lý.
  • Project detail không còn nhét task workspace trong tab.
  • Task board mặc định theo project đang chọn, nhưng toggle rõ sang toàn tổ chức.
  • Cross-domain action dùng CTA rõ ràng, không dùng tab ẩn.
