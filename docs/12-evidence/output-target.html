Hai realm. Ba user workspace. Năm board.

Project và Organization được tách theo mục đích sử dụng. System Admin được tách ở cấp principal, quyền, dữ liệu dùng chung, layout và URL — không phải một “vai trò nữa” của User.

System Admin ≠ User / Organization / Project

Ranh giới bảo mật

User realm

User principal

  • Personal
  • Organization Management nếu được phép
  • Project Workspace theo từng project truy cập được
  • Không có System role/permission hoặc nút Admin
không trộn
System realm

System Admin principal

  • Chỉ `/admin/*`
  • System role và System permission
  • Không organization/project membership trong shared props
  • Không workspace switcher sang User realm
