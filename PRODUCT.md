# Product

## Register

product

## Users

Suar serves authenticated users who need to work across organizations, projects, tasks, reviews, and a public task marketplace. Primary users include individual contributors, external marketplace applicants, organization members, project owners, project managers, organization admins, and system admins. In the user workspace, people are usually trying to find work, complete assigned tasks, respond to reviews, strengthen their profile, manage organization context, and understand what needs attention next.

## Product Purpose

Suar is a work management and capability verification platform. It connects real task delivery, multi-layer review workflows, skill evidence, trust scores, and profile snapshots so a user's stated ability can be backed by work history and review data. Product success means users can move through the loop of doing work, being reviewed, improving their profile, and being selected for more work with low friction and high trust.

## Brand Personality

Precise, evidence-driven, and operational. The interface should feel like a serious workbench for verified contribution: confident, direct, transparent, and humane without becoming decorative or marketing-heavy.

## Anti-references

Avoid generic SaaS landing-page styling inside authenticated surfaces, decorative dashboards that hide next actions, over-carded layouts, vague navigation labels, playful UI that weakens trust, and admin-heavy language in the user workspace. Avoid treating marketplace, reviews, profile evidence, and task delivery as disconnected islands.

## Design Principles

1. Make the user's next action obvious on every screen.
2. Keep evidence close to decisions: tasks, applications, reviews, skills, and profile trust should reinforce each other.
3. Separate personal work, organization work, marketplace exploration, and review obligations clearly.
4. Preserve operational density, but prevent empty space from feeling abandoned.
5. Use consistent navigation so users can always answer: where am I, what changed, and what should I do next?

## Accessibility & Inclusion

Target WCAG AA for authenticated product UI. Maintain keyboard access, visible focus states, readable contrast, reduced-motion support, clear Vietnamese and English labels, and layouts that remain usable on mobile and desktop.
